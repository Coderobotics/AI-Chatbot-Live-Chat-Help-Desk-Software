Frequently Asked Questions – Chat Pro
 
1. What is Chat Pro?
Chat Pro is a multi-tenant SaaS platform that combines an AI chatbot, live chat, help desk, help center and omnichannel inbox. You install it on your own server and sell plans to website owners. They each train an AI agent on their own content and add it to their site with one line of code.

2. Which AI models does Chat Pro support?
It works with OpenAI, Anthropic Claude, Google Gemini and any OpenAI-compatible API, such as Groq, DeepSeek, Mistral, xAI, OpenRouter and Ollama. You add the API key in Admin ? AI providers and test it with one click.

3. How does the AI learn about a business?
Each workspace has a knowledge base. It can crawl a website (sitemap and links), import single pages, and take uploads in PDF, DOCX, TXT, MD, CSV and HTML, plus text and Q&A entries. Published help center articles are added to the AI’s knowledge automatically.

4. Will the AI give wrong or made-up answers?
The AI answers only from the workspace’s own knowledge and cites its sources. When it can’t answer, it hands the chat to a human teammate. Questions it couldn’t answer go to an “Unanswered questions” list, so you can fill the gaps.

5. Which messaging channels are supported?
Website live chat, WhatsApp Cloud API, Facebook Messenger, Instagram Direct and Telegram. All channels share the same inbox and the same AI agent.

6. Can the AI perform actions like checking order status?
Yes. With AI actions, the agent can call your HTTP APIs as tools, for example to check order status, make bookings or update a CRM. Each action has a templated URL, headers and body, and a test runner.

7. How do I add the chat widget to a website?
Paste one tag before body. The widget includes Home, Messages and Help tabs, a pre-chat form, attachments, ratings and offline email capture. A JavaScript API lets you open, close and toggle it and identify visitors.

8. Can I charge customers for using Chat Pro?
Yes. It includes subscription plans with limits and features, free trials, invoices and payments through Stripe, PayPal, Razorpay or bank transfer. A fresh install comes with Free, Starter, Pro and Business plans, which you can edit.

9. Can I rebrand it with my own name and logo?
Yes. You can change the platform name, logo, colour and favicon, and edit the marketing site, pricing page and all transactional emails from the admin panel.

10. What are the server requirements?
PHP 8.3+ with the standard extensions, MySQL 8 or MariaDB 10.11+ (10.4 supported), and a cron job that runs every minute. WhatsApp, Messenger, Instagram and Telegram, PWA install and payment webhooks also need HTTPS on a public domain.

11. Does it work on shared hosting?
Yes. Chat Pro has a web installer that works on shared hosting or a VPS. It checks the server, connects the database, runs migrations and creates the super-admin account. You can also install it from the command line.

12. Is there demo data to explore the features?
Yes. One command, or one button in the admin panel, creates a demo workspace. It includes teammates, about 50 conversations, tickets, leads, help articles and a pre-trained AI agent.

13. Does Chat Pro support other languages and RTL?
Yes. You can add any language with a translation file, and Arabic, Hebrew, Persian and Urdu switch the interface to right-to-left. The widget follows the visitor’s browser language, and the AI replies in the visitor’s language.

14. Is there an API for integrations?
Yes. A REST API with bearer keys covers contacts, conversations, tickets, articles and knowledge. Signed webhooks fire for new conversations, messages, hand-overs, resolved chats, tickets and lead stage changes.

15. Is the source code encrypted?
No. You get the complete source code with no encryption and no domain limitations.

17. Do you provide installation and support?
You get unlimited email support and free updates for one year. Installation is not free; it costs $5 to $10, depending on the software’s complexity.

18. Can I use Chat Pro for multiple clients or resell it?
A regular license allows use in a single project, for personal or commercial purposes, by you or for a client. You may not resell the item or distribute its source files.
